# ISFAA Birthday Website

## Cara pakai
1. Taruh lima foto kalian di folder `images/` dengan nama:
   - `1.jpg`
   - `2.jpg`
   - `3.jpg`
   - `4.jpg`
   - `5.jpg`
2. Upload seluruh isi folder ini ke repository GitHub.
3. Aktifkan GitHub Pages dari Settings → Pages → Deploy from a branch → `main` → `/root`.
4. Setelah domain dibeli, arahkan DNS `isfaa.my.id` ke GitHub Pages.

Website ini dibuat mobile-first dengan lazy-loading foto dan animasi yang menghormati `prefers-reduced-motion`.
